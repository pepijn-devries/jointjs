# The JointJS Library

## JointJS and its History

JointJS is a JavaScript library originally released by Client IO, under
the [Mozilla Public License
2.0](https://www.mozilla.org/en-US/MPL/2.0/). But after version 3.7.7 it
is release under a commercial license. This R package wraps the latest
open source license.

This means that the underpinning library is no longer maintained and it
will not be updated. The R package will have to use the features that
are available from this library.

If you think certain features from this library are not ported to R,
please feel free to [submit an
issue](https://github.com/pepijn-devries/jointjs/issues).
